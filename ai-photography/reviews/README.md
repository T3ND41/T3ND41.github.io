# Independent review protocol

GLM records one review per task in this folder, named `TASK-00N-review-vNN.md`.

## Required contents

1. Task ID and the version of the generated image reviewed.
2. Original reference used, and which views are genuinely known.
3. Verdict: `APPROVED`, `REVISION REQUIRED`, or `REJECTED`.
4. Exact visual discrepancies, feature by feature — shape, proportions, colours, logos, labels, stitching, reflective strips, straps, buckles, safety components, background, and anything added or removed.
5. For revision requests, the specific correction required for each discrepancy.
6. Reviewer identity and timestamp.

## Rules

- A realistic-looking image is not automatically an accurate product photograph.
- A critical feature that is inaccurate, invented or unverifiable means the image does not pass.
- Miora may not record `APPROVED` without a verdict recorded here.
- Corrections go back through `AWAITING_REVIEW`; never approve your own correction.
