# T3ND41 Portfolio — Project Plan

## Vision
Build a professional portfolio that proves problem-solving ability through documented, working projects rather than a simple repository list.

## Positioning
**T3ND41 builds systems that solve problems.**

The portfolio connects design, development and marketing:
- Design: clarity, hierarchy, responsive UX and purposeful motion.
- Development: maintainability, safety, performance and accessible implementation.
- Marketing: positioning, proof, benefits, discoverability and strong next actions.

## Primary goals
1. Make the value of each flagship project understandable in under one minute.
2. Turn 3–5 strongest projects into deep case studies.
3. Standardize public repository documentation.
4. Keep the site fast, accessible and responsive.
5. Preserve the Hanekom production site while hosting the portfolio at /portfolio/.
6. Make future project additions predictable and easy.

## Flagship case studies
1. Hanekom Innovations Digital Platform
2. Windows Maintenance Toolkit
3. Windows System Health Toolkit
4. LicenseLab

## Definition of done for every flagship repository
- Clear one-sentence value proposition
- Problem and solution
- Key features
- How it works
- Safety/design decisions where relevant
- Install/run instructions
- Project structure
- Roadmap
- Known limitations
- License
- Portfolio case-study link

## Quality targets
- Responsive across mobile, tablet and desktop
- Keyboard-friendly navigation
- Respects prefers-reduced-motion
- No unnecessary frontend framework
- No console errors
- Minimal layout shift
- Clear metadata and page titles
- No broken project links
- No stale or contradictory public documentation

## Content rule
Every project must answer:
**What problem existed? What did I build? Why did I make those decisions? What value does it create? What did I learn? What comes next?**
