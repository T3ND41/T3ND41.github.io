# T3ND41 Portfolio

A lightweight static portfolio that documents real projects as problem-solving case studies.

## Live path

https://T3ND41.github.io/portfolio/

## Structure

```text
portfolio/
├── index.html
├── styles.css
├── app.js
├── PROJECT.md
└── projects/
    ├── hanekom.html
    ├── windows-maintenance.html
    ├── system-health.html
    └── licenselab.html
```

## Design goals

- Make value understandable quickly.
- Explain problem → approach → solution → value → next iteration.
- Stay fast and dependency-light.
- Work well on desktop and mobile.
- Respect reduced-motion preferences.
- Keep project source links obvious.
- Avoid decorative complexity that damages usability or performance.

## Local preview

Because the site is static, it can be previewed with any simple local HTTP server from the repository root.
